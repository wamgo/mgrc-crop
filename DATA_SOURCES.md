# Data sources and release boundary

## Upstream sources

- BreizhCrops: https://github.com/dl4sits/BreizhCrops and its distribution endpoint https://breizhcrops.s3.eu-central-1.amazonaws.com/. Acquisition uses the public benchmark archives, not a vendored upstream Python loader. Consult the provider for current data terms; the software license alone is not evidence of the license of every data layer.
- EuroCropsML: Zenodo record https://doi.org/10.5281/zenodo.15095445, used by `acquire_eurocropsml.py`; the research script records CC BY-SA 4.0. Users must follow the actual upstream record terms when downloading. The exact class mapping used here is supplied in the taxonomy JSONs, so the quick route does not need HCAT3.csv.
- ESA WorldCereal 2021: source links and product selection are preserved in `acquire_worldcereal.py`. This optional product audit is separate from the main phenology-group calibration results. See the accompanying source publication/provider for reuse terms.

## Included numerical artifacts

- `results/exp/v2/*.parquet`: per-setting/per-repetition aggregate measurements, no per-parcel arrays.
- `results/exp/v2_register/*.parquet`: separate register-group sensitivity, not main phenology results.
- Four taxonomy JSON files, domain definitions, aggregate supplementary class counts, accuracy summaries, aggregate map user-accuracy table, finite-population numerical checks, training metadata (when included) and archived reference statistics.
- `data/splits/*_ids.npz`: 18 ordered arrays of public-benchmark parcel identifiers. These are not anonymized aggregate data: they can be linked back to upstream parcels. They contain only `ids`, not owners, addresses, coordinates, crop labels or satellite features. Their purpose is to identify exactly the sampled domains. Do not interpret the original-code license as a license on third-party identifiers.

Source-domain files place the first 40,000 ordered samples in training, the next 5,000 in development, and the remainder in source holdout, as implemented by both training scripts. Target test/calibration splits are generated by the explicit experiment seeds in `run_v2.py`. Never substitute the earlier pilot `data/splits.json` for these ordered arrays.

## Excluded

Raw time series, labels and geometries, feature/sequence archives, probability archives, weights, `map_example.npz`, checkpoints, cached fonts, browser scripts and manuscript drafts are excluded. The map NPZ contains 60,000 parcel coordinates and labels; it is not an aggregate result. This exclusion is a conservative packaging boundary, not a claim that the upstream data are secret or legally forbidden to share.

Class counts needed for supplementary taxonomy tables were aggregated from the original probability archives at packaging time. The quick route uses these aggregate counts; the original label-based calculation remains available after regenerating probabilities.
