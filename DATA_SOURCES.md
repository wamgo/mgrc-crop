# Data sources and release boundary

## Upstream sources

- BreizhCrops: https://github.com/dl4sits/BreizhCrops and its distribution endpoint https://breizhcrops.s3.eu-central-1.amazonaws.com/. Acquisition uses the public benchmark archives, not a vendored upstream Python loader. The provider specifies the data terms separately from the software license.
- EuroCropsML: Zenodo record https://doi.org/10.5281/zenodo.15095445, used by `acquire_eurocropsml.py`; the research script records CC BY-SA 4.0. The upstream record specifies the terms for the downloaded data. The exact class mapping used here is supplied in the taxonomy JSONs, so the quick route does not need HCAT3.csv.
- ESA WorldCereal 2021: source links and product selection are preserved in `acquire_worldcereal.py`. This optional product audit is separate from the main phenology-group calibration results. The source publication and provider specify the reuse terms.

## Included numerical artifacts

- `results/exp/v2/*.parquet` contains per-setting and per-repetition aggregate measurements, without per-parcel arrays.
- `results/exp/v2_register/*.parquet` contains the separate register-group sensitivity results.
- The supporting files contain four taxonomy JSON files, domain definitions, aggregate supplementary class counts, accuracy summaries, an aggregate map user-accuracy table, finite-population numerical checks, training metadata and archived reference statistics.
- `data/splits/*_ids.npz` contains 18 ordered arrays of public-benchmark parcel identifiers. These are not anonymized aggregate data: they can be linked back to upstream parcels. They contain only `ids`, not owners, addresses, coordinates, crop labels or satellite features. Their purpose is to identify exactly the sampled domains. Third-party identifiers remain subject to their upstream terms.

Source-domain files place the first 40,000 ordered samples in training, the next 5,000 in development, and the remainder in source holdout, as implemented by both training scripts. Target test/calibration splits are generated by the explicit experiment seeds in `run_v2.py`. The earlier pilot `data/splits.json` describes a different sample and is not part of the v2 split definition.

## Excluded

Raw time series, labels and geometries, feature/sequence archives, probability archives, weights, `map_example.npz`, checkpoints, cached fonts, browser scripts and manuscript drafts are excluded. The map NPZ contains 60,000 parcel coordinates and labels; it is not an aggregate result. This exclusion is a conservative packaging boundary, not a claim that the upstream data are secret or legally forbidden to share.

Class counts needed for supplementary taxonomy tables were aggregated from the original probability archives at packaging time. The quick route uses these aggregate counts; the original label-based calculation remains available after regenerating probabilities.
